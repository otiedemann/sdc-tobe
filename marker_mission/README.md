# Marker-mission control for Parrot Anafi

Documentation lives in [`docs/`](docs/):

- [`docs/README.md`](docs/README.md) — overview, conventions, layout,
  install / configure / fly / artefacts.
- [`docs/MISSION_REFERENCE.md`](docs/MISSION_REFERENCE.md) —
  plain-English reference for every script command and flight phase.
- [`docs/MISSION_REFERENCE_DETAILED.md`](docs/MISSION_REFERENCE_DETAILED.md)
  — detailed reference with deadbands, settle times, recovery paths,
  and pointers into `controller.py` / `mission_script.py`.
- [`docs/REPROCESS_FLIGHT.md`](docs/REPROCESS_FLIGHT.md) — offline
  re-processor that re-runs the detector + arena estimator over a
  recorded flight and produces OLD-vs-NEW comparison videos.
